字灵 · 快速上手

本页是开发者控制台：侧栏参数较密。下列顺序与 DESIGN.md（产品真源）一致；若与旧文档矛盾，以 DESIGN.md 较晚条目为准。

入门三步

  1. 底部输入文稿 → 右侧点「呈」，画布出现与输入行序一致的字列（一格一字）。
  2. 点「灵」或双击文稿区 → 化为字灵。
  3. 左侧「层」在待机（数学曲线、软团）与呈现（巨字、计时、颜文字）之间切换；色、走格、灰底/淡影/内动等分套记忆（体内节拍与沿格追赶已统一为低速常量）。

沙拨字（拨沙 / 贴边散）

左栏第②区最上一行点「沙拨字」打开后：在字灵画布任意位置按下再拖，会像划过沙子一样推开体内字粒，整体身位不跟拖（须为走格形态）。关「沙拨字」后恢复为拖移整体；拖整体顶活动区边时字粒会沿边顺滑摊开（非高频随机撞散，更省算力）。字粒靠近活动区边缘时会轻散再向心聚回。若侧栏未刷新，请强刷（无痕或清缓存）并看页眉构建号。

回稿（还原文稿）

在字灵核心区长按约 0.58 秒至 Toast 提示 → 松手即回文稿（移动超过约 8px 视为拖拽并取消回稿）。也可随时点右侧「回」。

巨字 / 颜文字与「先静后动」

呈现层巨字/颜的轮廓应由小字拼出——画布不再叠整张 mask 大字底。巨字乱时先点「规整」（约 0.9s 内不邻格换位，之后节律换位且关内动下会淡隐再接淡入），再用「谐步 / 廊道」二选一（待机层另有「漫游」）；「字号」统一调躯体字大小。侧栏「排布」在拼满画布（短串也分行、按画布收紧格距）与逐字轮换之间切换；「颤幅」调亚格颤的位移幅度（须开「颤」）。拖曳呈现巨字/颜时剪影中心跟手（每帧格迈与叠分用跟手中心；松手才把字灵锚点对齐），格向残差减轻整块平移感；关内动下谐步微颤略柔、邻格换位轻淡。「整块灰底」「淡影」仅在待机层侧栏出现，用于调试对比。「内动」开时体内跑谐波/流体/蛇行等；关切到开时字粒会短时略闪确认。

常用 URL 参数

  • ?skipIntro=1 或 ?pet=1 — 跳过开场空白
  • ?form=mega&macroText=春 — 巨字
  • ?form=clock / ?form=chrono — 计时
  • ?uiArc=presentation — 直接进入呈现层侧栏形态区
  • ?dev=1 — 活动区虚线；右上显示上一帧 frame/upd/ren 与 resize，换形后另有 setForm 分段与 suggestMemo 等
