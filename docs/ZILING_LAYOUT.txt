字灵仓库结构（便于后续改代码、省上下文 token）
=============================================

页面
  index.html       入口；侧栏分区 + 各控件 title；#helpDialog 入门说明（?）；先加载 js/ziling/*.js 再 pet.js、app.js
  styles.css       样式
  app.js           「层」+ 轨/颤/紊/廓/辨/动/波/徙/粒/字比/容纳；toast 标明 arcLayer；色盘写入当前层

引擎（单文件，体量仍大）
  pet.js           剪影谐波/蛇行/颤；形场重建、packedHash；纹理体动流/序（关格移时邻换）

可拆出的小模块（按需再细分）
  js/ziling/play-bounds.js   画布内碰撞夹紧与反弹
  js/ziling/shape-field.js   可走格 + 壳层 + Uint8Array 密铺（辨形 / 矩阵伏笔）
  js/ziling/matrix-bridge.js  矩阵预处理 + 二值栅格重采样（对齐外部与本地密铺）
  js/ziling/shape-consumer.js 形场 Consumer（外部 walk 时间平滑 + 对齐）

对外
  window.ZiLing = { Pet, FORMS, FORM_ORDER, STANDBY_MATH_ORDER, getFormOrderForUiArcMode, getMotionProfileKernelsForPet, ... }

设计/计划
  DESIGN.md        产品意图与变更摘要
  PLAN.md          需求对照与版本号
  HANDOFF.md       接手说明 + §12 控件映射（改侧栏必同步 title 与表）
