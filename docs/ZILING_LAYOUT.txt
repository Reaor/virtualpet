字灵仓库结构（便于后续改代码、省上下文 token）
=============================================

页面
  index.html       入口；先加载 js/ziling/*.js 再 pet.js、app.js
  styles.css       样式
  app.js           「层」+ 波/徙/粒；toast 标明 arcLayer；色盘写入当前层

引擎（单文件，体量仍大）
  pet.js           bodyMotionStyle/轨；蛇行走廊 _snakeWalkPath；DESIGN 2.6-2.7 对照

可拆出的小模块（按需再细分）
  js/ziling/play-bounds.js   画布内碰撞夹紧与反弹；pet 里 _playBounds / _applyPlayfieldBounds

对外
  window.ZiLing = { Pet, FORMS, FORM_ORDER, STANDBY_MATH_ORDER, getFormOrderForUiArcMode, getMotionProfileKernelsForPet, ... }

设计/计划
  DESIGN.md        产品意图与变更摘要
  PLAN.md          需求对照与版本号
